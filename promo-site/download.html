Mac · Apple Silicon

Mac 客户端

MianshiZhu Pro，面向 macOS arm64。全新支持一键静默截屏、防录屏隐身与置顶鼠标穿透幽灵模式。

  • 全局静默截屏答题（Cmd+Shift+S）
  • 防录屏隐身：腾讯会议/Zoom完全不可见
  • 置顶并透过（Cmd+Shift+P 穿透操作网页）
  • 5档透明度快速调节
从 GitHub 下载最新版 Mac 安装教程

当前最新版 v1.0.8，Apple Silicon（arm64）。打开 GitHub Releases 下载 MianshiZhu Pro-1.0.8-arm64.dmg，拖入「应用程序」即可。

Windows · x64

Windows 客户端

MianshiZhu Pro，适用于 Windows 10 / Windows 11。支持全套防截屏保护与全局快捷键辅助答题。

  • 全局静默截屏答题（Ctrl+Shift+S）
  • 防截屏/屏幕共享隐身：监考会议不可见
  • 置顶并透过（Ctrl+Shift+P 穿透操作网页）
  • 5档透明度与双版本（安装包 / 免安装ZIP）
从 GitHub 下载最新版

当前最新版 v1.0.8，Windows x64。可下载 MianshiZhu Pro-1.0.8-win-x64.exe 安装包或 .zip 免安装直接运行。

系统要求

网页版：最新 Chrome / Edge。Mac：macOS 13+，Apple Silicon（arm64）。建议稳定网络，避免校园网限制。

首次权限

Mac 需授权麦克风与屏幕录制，否则无法捕获系统音频。系统设置 → 隐私与安全性 中可补开。
