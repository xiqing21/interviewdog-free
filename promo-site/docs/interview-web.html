💻 网页版教程

约 5 分钟完成：登录 → 配简历 → 开系统音频 → 跑通一轮问答。

1. 打开方式

  1. 建议使用 最新版 Chrome 或 Edge（Chromium）。
  2. 访问 https://mianshizhu.cn/interview
  3. 注册 / 登录账号（手机号或邮箱，以页面为准）。
Safari 对系统音频共享支持有限，正式面试请优先 Chrome。

2. 准备材料（强烈建议）

1
简历
上传 PDF 或粘贴文本，确保项目描述完整
2
岗位 JD
粘贴目标岗位描述，帮助回答对齐招聘要求
3
知识库
导入专家 QA、项目笔记、八股要点、自定义热词

3. 系统音频（听面试官）

  1. 进入「面试」工作台，点击开始识别 / 共享音频。
  2. 在 Chrome 弹窗中选择会议标签页或窗口。
  3. 务必勾选底部 同时分享系统音频 / Share tab audio。
  4. 说一句测试语，确认面试官侧转写出现在「面试官问题」区域。
未勾选系统音频时，只能听到你自己麦克风，无法可靠识别面试官。这是最常见的配置失误。

4. 实时回答怎么用

  • 自动：面试官说完并停顿后，自动生成回答。
  • 手动：识别到问题但没触发时，点「生成 / 手动触发」。
  • 重写：可切换精简、详细、STAR 结构，或清除上下文后再答。
  • 编辑问题：识别有误时可手动改正题干再生成。

5. 正式面试建议

  • 提前 10 分钟进入会议，再开面试猪并测音频。
  • 眼睛仍以镜头与面试官为主，答案只作扫读提示。
  • 把回答用自己的话讲出来，避免机械朗读。
  • 面试结束点归档，生成复盘并补知识库。

6. 环境建议

  • 安静环境，减少背景噪音。
  • 网络稳定；必要时关闭多余 VPN 分流。
  • 额度不足时先到 套餐页 充值。
