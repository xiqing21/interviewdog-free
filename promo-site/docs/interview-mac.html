🖥 Mac 客户端教程

MianshiZhu Pro 面向 macOS（Apple Silicon）。相比网页版，更适合需要系统音频直采、浮层透明度、屏幕共享内容保护的正式面试。

1. 安装

  1. 从 GitHub Releases 下载最新 .dmg 安装包。
  2. 打开 DMG，将「MianshiZhu Pro」拖入「应用程序」。
  3. 首次打开若提示未验证开发者：系统设置 → 隐私与安全性 → 仍要打开。
系统要求：macOS 13+，Apple Silicon（arm64）。

2. 权限（必须）

首次启动会请求权限，也可在「系统设置 → 隐私与安全性」中手动开启：

  • 麦克风：记录你的表达，用于对话上下文与复盘。
  • 屏幕录制：用于捕获系统音频（面试官声音）以及会议窗口相关能力。
没有「屏幕录制」权限时，系统音频通常无法工作，面试官问题会识别失败。改完权限后请完全退出 App 再重开。

3. 登录与资料同步

  1. 使用与网页版相同的账号登录。
  2. 确认简历库、知识库、额度已同步。
  3. 在设置中确认 ASR / 模型相关配置可用（商业版一般已预置网关）。

4. 开始一场面试

1
打开腾讯会议 / 飞书 / Zoom，进入会议室（可先静音自测）
2
打开面试猪，进入面试工作台，开启识别
3
播放一段会议声音，确认「面试官问题」区域出现转写
4
观察 AI 回答是否结合简历；必要时切换 STAR / 精简模式

5. 窗口体验

  • 拖拽：无边框窗口可从顶栏 / 侧栏空白处拖动。
  • 透明度：设置中可调，最低约 35%，避免完全看不见。
  • 内容保护：开启后，屏幕共享与系统截图中本窗口对对方不可见。详见 隐身说明。

6. 常见故障

  • 听不到面试官：检查屏幕录制权限；重启 App；确认会议有声音输出。
  • 延迟高：检查网络；关闭多余 VPN；尽量有线或稳定 Wi-Fi。
  • 窗口被共享露出来：确认内容保护已开；不要用会绕过系统共享限制的特殊采集工具。
