使用前必读

  • 尽量使用稳定网络；校园网 / 严格代理环境可能影响识别与模型请求。
  • 正式面试前至少做一次「系统音频共享」自测。
  • 回答质量高度依赖简历、JD 与知识库的完整度——请提前准备。
  • 本工具仅供学习与技术研究，请遵守相关法律法规与平台规则。
